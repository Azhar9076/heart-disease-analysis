Heart Disease Analysis

This repository contains a complete exploratory data analysis (EDA) of the classic Heart Disease dataset.

### What’s included
- Data cleaning (nulls, duplicates)
- Statistical summary
- Correlation matrix
- Distribution analysis of categorical & continuous features
- Visualization of key risk factors (age, gender, chest pain type, blood pressure, cholesterol, etc.)

### Tools used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Dataset
`heart.csv` – 1025 records with 14 features related to heart disease prediction.
